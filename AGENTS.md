# Instruções para o Codex

Leia o arquivo `documentacao-uva-moda-fitness.md` antes de criar ou alterar qualquer código.

Objetivo:
Criar um e-commerce chamado Uva Moda Fitness.

Tecnologias:
- Frontend: React.js + Vite
- Backend: Node.js + Express
- Banco: MySQL
- Autenticação: JWT
- Senhas com bcrypt
- CSS separado por componente

Identidade visual:
- Usar a logo `logo-uva-moda-fitness.png`
- Cor 1: `#510A50`
- Cor 2: `#ACCD46`
- Cor 3: `#EC0FD3`

Estrutura desejada:
- `/frontend`
- `/backend`

Sempre criar código organizado, responsivo e fácil de manter.
